# 页面地图

## 概述

本文档定义了心语小程序的所有页面结构、路由配置和功能说明。

---

## 页面结构图

```
┌─────────────────────────────────────────────────────┐
│                    心语小程序                        │
├─────────────────────────────────────────────────────┤
```

## TabBar 页面

### 1. 首页

- **路径**: `pages/index/index`
- **标题**: 心语
- **导航栏**: 自定义样式，粉色背景

#### 功能模块

| 模块 | 说明 |
|------|------|
| 今日心情卡片 | 展示今日心情状态，可点击添加新心情 |
| 心情记录入口 | 快速记录心情按钮 |
| 心情日历 | 月视图心情日历 |
| 每日建议 | 根据今日心情显示情绪建议 |
| 快捷入口 | 日记、统计等功能入口 |

## 页面路由表

| 页面路径 | 页面名称 | 导航方式 | 说明 |
|---------|---------|---------|------|
| `/pages/auth/index` | 登录/注册 | 页面跳转 | 未登录时自动跳转 |
| `/pages/index/index` | 首页 | TabBar | 底部导航 |
| `/pages/mood/add/index` | 记录心情 | 页面跳转 | 从首页或日历进入 |
| `/pages/diary/index` | 我的日记 | TabBar | 底部导航 |
| `/pages/diary/detail/index` | 日记详情 | 页面跳转 | 从日记列表进入 |
| `/pages/diary/write/index` | 写日记 | 页面跳转 | 从日记列表进入 |
| `/pages/world/index` | 世界 | TabBar | 底部导航 |
| `/pages/user/profile/index` | 用户主页 | 页面跳转 | 从世界或好友列表进入 |
| `/pages/friend/index` | 好友 | TabBar | 底部导航 |
| `/pages/chat/index` | 聊天 | 页面跳转 | 从好友列表进入 |
| `/pages/statistics/index` | 统计分析 | 页面跳转 | 从个人中心进入 |
| `/pages/profile/index` | 个人中心 | TabBar | 底部导航 |
| `/pages/profile/edit/index` | 编辑资料 | 页面跳转 | 从个人中心进入 |

## 页面跳转关系

```
登录页 ──登录成功──→ 首页
首页 ──点击记录──→ 记录心情页
首页 ──点击日记入口──→ 日记列表页
首页 ──点击统计入口──→ 统计分析页
首页 ──点击用户──→ 用户主页
日记列表页 ──点击日记──→ 日记详情页
日记列表页 ──点击写日记──→ 写日记页
日记详情页 ──点击编辑──→ 写日记页（编辑模式）
世界页 ──点击用户──→ 用户主页
世界页 ──点击日记──→ 日记详情页
好友页 ──点击好友──→ 用户主页/聊天页
好友页 ──点击聊天──→ 聊天页
好友页 ──点击添加──→ 添加好友（弹窗）
个人中心页 ──点击编辑──→ 编辑资料页
个人中心页 ──点击统计──→ 统计分析页
个人中心页 ──点击日记──→ 日记列表页
个人中心页 ──点击聊天──→ 聊天页
```
