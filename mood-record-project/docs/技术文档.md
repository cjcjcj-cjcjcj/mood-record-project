# 心语项目技术文档

## 第一章 绪论

### 1.1 课题背景及意义

随着现代生活节奏的加快，人们面临着越来越多的压力和挑战。心理健康问题日益受到关注，越来越多的人开始重视情绪管理和心理调节。然而，传统的心理咨询方式存在门槛高、费用贵、隐私顾虑等问题，使得许多人在需要帮助时无法及时获得支持。

移动互联网的普及为心理健康服务提供了新的可能性。微信小程序作为一种轻量级应用，无需下载安装即可使用，具有用户基数大、使用便捷、传播快速等优势，为心理健康应用的开发提供了理想的平台。

"心语"项目正是在这样的背景下诞生的。它是一款基于微信小程序的心情记录与社交应用，旨在为用户提供一个私密、安全、便捷的情绪管理工具。通过记录每日心情、撰写日记、与好友互动交流，用户可以更好地了解自己的情绪变化，获得情感支持，打造一个温暖的情绪管理社区。

本项目的意义主要体现在以下几个方面：

1. **情绪管理**：帮助用户记录和追踪自己的情绪变化，培养情绪自我觉察能力
2. **情感支持**：通过好友互动和社区分享，为用户提供情感支持和陪伴
3. **心理疏导**：提供情绪建议和温暖的心理支持，帮助用户缓解压力
4. **社交连接**：建立基于真实情感的社交关系，减少孤独感
5. **隐私保护**：提供多种可见性设置，让用户可以自主控制信息的分享范围

### 1.2 国内外研究现状

#### 1.2.1 国外研究现状

在国外，心理健康类应用已经发展得较为成熟。根据市场研究机构的数据，全球心理健康应用市场规模在2020年已超过40亿美元，预计到2027年将达到170亿美元。

知名的应用包括：

- **Headspace**：提供冥想和正念训练，帮助用户减轻压力和焦虑
- **Calm**：专注于睡眠、冥想和放松，拥有超过1亿用户
- **Moodpath**：提供心理健康评估和个性化建议
- **Daylio**：日记应用，通过追踪心情和活动来改善心理健康
- **Talkspace**：提供在线心理咨询服务

这些应用在功能设计、用户体验、数据安全等方面都有较高的水准，为心理健康服务提供了良好的示范。

#### 1.2.2 国内研究现状

在国内，心理健康类应用的发展相对较晚，但近年来也取得了快速发展。随着人们对心理健康重视程度的提高，越来越多的心理健康应用涌现出来。

国内知名的应用包括：

- **壹心理**：提供心理测试、心理咨询、心理课程等服务
- **简单心理**：专注于专业心理咨询，拥有大量专业咨询师
- **壹点灵**：提供在线心理咨询和心理测试服务
- **心潮减压**：通过音乐、冥想等方式帮助用户减压
- **心情日记**：简单的日记应用，帮助用户记录心情

然而，国内的心理健康应用普遍存在以下问题：

1. **功能复杂**：很多应用功能过于复杂，用户学习成本高
2. **商业化严重**：过度商业化，影响用户体验
3. **隐私保护不足**：用户数据安全存在隐患
4. **社交属性弱**：缺乏真实的社交互动，难以形成社区氛围
5. **门槛高**：很多应用需要付费才能使用完整功能

"心语"项目针对这些问题，采用简洁的设计理念，提供免费的基础功能，注重隐私保护，强化社交属性，旨在为用户提供一个真正有用的心理健康工具。

## 第二章 识别需求

### 2.1 需求陈述

"心语"项目旨在为用户提供一个私密、安全、便捷的心情记录与社交平台。用户可以通过该应用记录每日心情、撰写日记、与好友互动交流，获得情感支持，打造一个温暖的情绪管理社区。

核心需求包括：

1. 用户可以注册账号并登录应用
2. 用户可以记录每日心情，支持多种心情类型
3. 用户可以撰写日记，支持多种可见性设置
4. 用户可以添加好友，与好友进行私信聊天
5. 用户可以浏览公开的日记和心情记录（世界广场）
6. 用户可以查看自己的心情统计数据
7. 用户可以编辑个人资料，包括昵称、头像、生日等
8. 系统根据用户的心情提供情绪建议

### 2.2 产品分析

#### 2.2.1 目标用户

**主要用户群体：**

1. **年轻人**：18-35岁的年轻人，面临学业、工作、恋爱等多方面压力
2. **职场人士**：工作压力大，需要释放压力、调节情绪的职场人士
3. **学生群体**：面临学业压力和成长困惑的学生
4. **独居人群**：缺乏社交支持，需要情感陪伴的独居人群

**用户特征：**

- 熟悉智能手机操作
- 有一定的隐私保护意识
- 希望获得情感支持和陪伴
- 愿意分享自己的心情和经历

#### 2.2.2 产品定位

"心语"定位为一款**私密、温暖、便捷**的心情记录与社交应用。

- **私密**：提供多种可见性设置，用户可以自主控制信息的分享范围
- **温暖**：通过情绪建议、好友互动等方式，为用户提供温暖的心理支持
- **便捷**：基于微信小程序，无需下载安装，随时随地使用

### 2.3 业务流程

#### 2.3.1 用户注册登录流程

```
用户打开应用 → 检查是否已登录 → 未登录 → 进入登录/注册页面
→ 用户输入用户名和密码 → 系统验证用户信息
→ 验证成功 → 生成JWT Token → 跳转首页
→ 验证失败 → 提示错误信息
```

#### 2.3.2 心情记录流程

```
用户进入首页 → 点击"记录心情"按钮 → 选择心情类型
→ （可选）输入心情描述 → （可选）选择可见性设置
→ 提交记录 → 系统保存心情记录 → 返回首页，显示记录的心情
```

#### 2.3.3 日记撰写流程

```
用户进入日记页面 → 点击"写日记"按钮 → 输入日记标题和内容
→ （可选）选择心情标签 → （可选）上传背景图片
→ 选择可见性设置 → 提交日记 → 系统保存日记记录 → 返回日记列表
```

#### 2.3.4 好友添加流程

```
用户进入好友页面 → 点击"添加好友"按钮 → 输入目标用户名
→ 系统搜索用户 → 找到用户 → 发送好友请求
→ 对方收到好友请求 → 对方选择接受或拒绝
→ 接受 → 建立好友关系 / 拒绝 → 删除好友请求
```

##### 3.3.3.1 用户注册登录时序图

**交互流程说明：**

1. **用户发起注册请求**
   - 用户在前端页面填写用户名、密码，点击注册按钮
   - 前端对输入数据进行基础验证（用户名非空、密码长度等）
   - 验证通过后，前端调用用户注册API

2. **前端发送注册请求**
   - 前端发送POST请求到 `/api/user/register`
   - 请求参数包含：username（用户名）、password（密码）、nickname（昵称）

3. **后端处理注册请求**
   - 后端接收请求，验证参数完整性
   - 查询数据库，检查用户名是否已存在
   - 如果用户名已存在，返回错误信息
   - 如果用户名可用，使用bcrypt算法对密码进行加密
   - 将用户信息插入数据库users表
   - 生成JWT Token，包含用户ID和用户名
   - 返回用户信息和Token给前端

4. **前端处理注册响应**
   - 前端接收到注册成功的响应
   - 将用户信息和Token存储到本地（Storage或Pinia状态管理）
   - 跳转到首页或指定页面
   - 显示注册成功的提示信息

**登录流程与注册类似，主要区别：**

- 后端先查询用户是否存在
- 验证用户密码是否正确（bcrypt.compare）
- 验证通过后生成新的JWT Token并返回

##### 3.3.3.2 心情记录时序图

   - 用户在心情记录页面，从6种心情类型中选择一种
   - 心情类型包括：开心(1)、平静(2)、焦虑(3)、难过(4)、生气(5)、烦躁(6)
   - 用户可以输入心情描述文字

2. **用户提交心情记录**
   - 用户点击提交按钮
   - 前端收集心情数据：mood_type（心情类型）、content（心情描述）
   - 前端调用心情记录API

3. **前端发送添加心情请求**
   - 前端发送POST请求到 `/api/mood/add`

   - 请求参数包含：mood_type、content、record_date（记录日期）

4. **后端验证用户身份**
   - JWT中间件验证Token有效性
   - 从Token中提取用户ID
   - 如果Token无效或过期，返回认证失败错误

5. **后端处理心情记录**

   - 获取当前日期和时间
   - 将心情记录插入数据库moods表
   - 更新用户的心情统计数据

6. **返回结果并更新界面**
   - 后端返回添加成功响应
   - 前端更新首页显示的今日心情
   - 更新日历组件中当天的显示

##### 3.3.3.5 聊天时序图

**交互流程说明：**

1. **用户进入聊天页面**
   - 用户从好友列表选择一个好友进入聊天界面
   - 前端获取当前用户ID和好友ID
   - 调用获取聊天记录API

2. **前端发送获取聊天记录请求**
   - 前端发送GET请求到 `/api/chat/list`
   - 请求参数包含：to_user_id（对方用户ID）

3. **后端处理聊天记录请求**
   - JWT验证用户身份
   - 查询messages表中双方的消息记录
   - 按时间升序返回聊天记录
   - 返回的消息包含发送者信息（nickname、avatar）

4. **用户发送消息**
   - 用户在输入框输入消息内容
   - 点击发送按钮
   - 前端发送POST请求到 `/api/chat/send`

5. **后端处理发送消息**
   - JWT验证发送者身份
   - 验证接收者是否存在
   - 将消息插入messages表
   - 设置消息状态为未读（is_read=0）

6. **返回发送结果**
   - 后端返回发送成功的消息
   - 前端更新聊天界面显示新消息
   - 将消息添加到消息列表末尾

7. **接收方接收消息**
   - 接收方前端轮询或WebSocket获取新消息
   - 前端更新聊天界面

#### 4.1.1 用户模块

| /api/user/login         | POST | 用户登录 |
| /api/user/upload-avatar | POST | 上传头像 |

// 注册：验证用户名 → bcrypt加密 → 插入数据库 → 返回Token和用户信息
app.post("/api/user/register", async (req, res) => {
  const { username, password, nickname } = req.body;
  const [exist] = await pool.query("SELECT id FROM users WHERE username = ?", [
    username,
  ]);
  if (exist.length)
    return res.json({ success: false, message: "用户名已存在" });
  const hash = await bcrypt.hash(password, 10);
  const [r] = await pool.query(
    "INSERT INTO users (username, password, nickname) VALUES (?, ?, ?)",
    [username, hash, nickname || username],
  );

    expiresIn: "7d",
  });

    [r.insertId],
  );

});

// 登录：查询用户 → bcrypt验证密码 → 返回Token和用户信息

  const [users] = await pool.query("SELECT * FROM users WHERE username = ?", [
    username,
  ]);
  if (!users.length || !(await bcrypt.compare(password, users[0].password)))
    return res.json({ success: false, message: "用户名或密码错误" });
  const token = jwt.sign({ userId: users[0].id }, JWT_SECRET, {
    expiresIn: "7d",
  });
  res.json({
    success: true,
    data: {
      user: {
        id: users[0].id,
        username,
        nickname: users[0].nickname,
        avatar: users[0].avatar,
      },
      token,
    },
  });
});

// 上传头像：multer处理文件 → 更新数据库 → 返回新用户信息

  "/api/user/upload-avatar",
  verifyToken,
  upload.single("avatar"),

    if (!req.file) return res.json({ success: false, message: "请选择图片" });
    await pool.query("UPDATE users SET avatar = ? WHERE id = ?", [
      "/uploads/" + req.file.filename,
      req.userId,

```javascript
// 添加心情：接收心情类型、内容、可见性、日期 → 插入数据库 → 返回新记录
app.post("/api/mood/add", verifyToken, async (req, res) => {
  const { mood_type, content, visibility, record_date } = req.body;
  const date = record_date || new Date().toISOString().split("T")[0];
  const [r] = await pool.query(
    "INSERT INTO moods (user_id, mood_type, content, visibility, record_date, record_time) VALUES (?, ?, ?, ?, ?, ?)",
    [
      req.userId,
      mood_type,
      content,
      visibility || 1,
      date,
      new Date().toTimeString().split(" ")[0],
    ],
  );
  const [m] = await pool.query("SELECT * FROM moods WHERE id = ?", [
    r.insertId,
  ]);
  res.json({ success: true, data: m[0] });
});

// 心情日历：按月份查询 → 按日期分组 → 返回{日期: [心情列表]}格式
app.get("/api/mood/calendar", verifyToken, async (req, res) => {
  const month = req.query.month || new Date().toISOString().slice(0, 7);
  const [moods] = await pool.query(
    "SELECT * FROM moods WHERE user_id = ? AND record_date LIKE ?",
    [req.userId, `${month}%`],
  );
  const data = {};
  moods.forEach((m) => {
    (data[m.record_date] = data[m.record_date] || []).push(m);
  });
  res.json({ success: true, data });
});

// 心情统计：按周期筛选 → 按心情类型分组计数 → 返回总数和分布
app.get("/api/mood/stat", verifyToken, async (req, res) => {
  const { type } = req.query;
  let cond = "";
  if (type === "week") {
    const s = new Date(),
      e = new Date(s);
    s.setDate(s.getDate() - s.getDay() + 1);
    e.setDate(s.getDate() + 6);
    cond = `AND record_date BETWEEN '${s.toISOString().split("T")[0]}' AND '${e.toISOString().split("T")[0]}'`;
  } else if (type === "month")
    cond = `AND record_date LIKE '${new Date().toISOString().slice(0, 7)}%'`;
  else if (type === "year")
    cond = `AND record_date LIKE '${new Date().toISOString().slice(0, 4)}%'`;
  const [stats] = await pool.query(
    `SELECT mood_type, COUNT(*) as c FROM moods WHERE user_id = ? ${cond} GROUP BY mood_type`,
    [req.userId],
  );
  const dist = {};
  stats.forEach((s) => (dist[s.mood_type] = s.c));
  res.json({
    success: true,
    data: {
      total_count: stats.reduce((sum, s) => sum + s.c, 0),
      distribution: dist,
    },
  });
});

// 统计总览：COUNT DISTINCT record_date计算总天数 → COUNT(*)计算总记录数
app.get("/api/mood/stats", verifyToken, async (req, res) => {
  const [days] = await pool.query(
    "SELECT COUNT(DISTINCT record_date) as c FROM moods WHERE user_id = ?",
    [req.userId],
  );
  const [count] = await pool.query(
    "SELECT COUNT(*) as c FROM moods WHERE user_id = ?",
    [req.userId],
  );
  res.json({
    success: true,
    data: { total_days: days[0].c, total_count: count[0].c },
  });
});
```

// 添加好友：查询目标用户 → 检查是否已是好友 → 插入待确认记录
app.post("/api/friend/add", verifyToken, async (req, res) => {
  const { username } = req.body;
  const [u] = await pool.query("SELECT id FROM users WHERE username = ?", [
    username,
  ]);

app.get("/api/friend/list", verifyToken, async (req, res) => {

});

// 待处理请求：查询发给当前用户且状态为0的请求

  );
  res.json({ success: true, data: r });
});

// 接受请求：更新状态为1；拒绝请求：删除记录
app.post("/api/friend/accept", verifyToken, async (req, res) => {
  await pool.query("UPDATE friends SET status = 1 WHERE id = ?", [req.body.id]);
  res.json({ success: true });
});
app.post("/api/friend/reject", verifyToken, async (req, res) => {

心语小程序包含十个核心页面：登录页面作为应用入口，展示 logo 和标语，用户通过用户名和密码登录或注册，验证通过后保存用户信息和 Token 跳转首页；首页是核心功能页面，顶部显示问候语和日期，中间为日历组件展示当月心情记录，下方显示今日心情区域，未记录时提示"今天还没有记录心情"，底部五栏导航包含首页、世界、日记、好友、我的；记录心情页面提供开心、平静、焦虑、难过、生气、疲惫六种心情选择，用户填写描述后提交到指定日期，成功后返回首页刷新日历；统计分析页面支持本周、本月、本年切换，展示情绪统计、心情分布条形图和每日心情趋势柱状图；个人中心页面展示用户头像、用户名、昵称及统计数据，功能菜单包含我的日记、统计分析、设置，快捷操作提供记录心情、写日记、探索世界、好友入口；世界页面展示其他用户公开的心情和日记，每条内容显示用户信息、心情图标和时间，支持查看详情和添加好友；写日记页面提供心情标签选择、内容输入和可见范围设置（私密/好友可见/全部可见），保存成功后提示；我的日记页面支持搜索和筛选，列表显示日记摘要、日期和可见范围，点击跳转详情；好友页面包含搜索框、好友列表和好友请求标签页，好友列表显示已添加好友，请求页面提供接受和拒绝按钮；聊天页面显示好友信息和历史消息列表，发送消息后实时添加到列表并自动滚动。

## 总结

"心语"项目是一款基于微信小程序的心情记录与社交应用，旨在为用户提供一个私密、安全、便捷的情绪管理工具。本项目采用前后端分离的架构设计，前端使用UniApp + Vue3 + TypeScript + Pinia技术栈，后端使用Node.js + Express.js + MySQL技术栈。

通过本项目的开发，实现了以下核心功能：

1. **用户管理**：用户注册、登录、个人信息管理、头像上传、密码修改等功能
2. **心情管理**：心情记录、心情日历、心情统计、世界广场心情等功能
3. **日记管理**：日记撰写、日记列表、日记详情、日记编辑/删除、世界广场日记等功能
4. **好友管理**：添加好友、好友列表、好友请求、删除好友等功能
5. **聊天功能**：发送消息、聊天记录、未读消息、消息已读等功能
6. **情绪建议**：根据心情类型提供情绪建议功能

本项目在开发过程中，注重以下几点：

1. **简洁设计**：采用简洁的设计理念，界面美观，操作直观
2. **隐私保护**：提供多种可见性设置，用户可以自主控制信息的分享范围
3. **安全防护**：使用bcrypt加密存储密码，JWT认证保护用户数据安全
4. **性能优化**：优化数据库查询，提高系统响应速度
5. **跨端开发**：基于UniApp框架，支持微信小程序、H5等多端运行

通过本项目的开发，不仅掌握了UniApp + Vue3 + TypeScript + Pinia前端技术栈和Node.js + Express.js + MySQL后端技术栈，还深入了解了前后端分离架构的设计和实现，积累了宝贵的项目开发经验。

未来，本项目可以继续完善和扩展，增加更多功能，如心情分享、数据导出、夜间模式等，进一步提升用户体验，打造一个更加完善的心情记录与社交平台。
