# 心语小程序原型图

## 项目概述

**心语小程序**是一个心情记录和分享平台，帮助用户记录每日心情、撰写日记、与好友交流。

**设计风格：**
- 主色调：粉色系 (#FFB6C1, #FF69B4)
- 背景色：浅粉色渐变 (#FFF5F5)
- 卡片风格：圆角卡片，柔和阴影
- 交互风格：简洁流畅，符合微信小程序规范

---

## 交互规范

### 按钮交互

- **主要按钮**：渐变背景，点击时缩小0.95倍
- **次要按钮**：白色背景，边框，点击时缩小0.95倍
- **图标按钮**：透明背景，点击时放大1.1倍

### 列表交互

- **卡片点击**：点击时背景色变浅
- **长按**：显示操作菜单（编辑、删除、分享）

### 输入交互

- **获得焦点**：边框颜色变为主色
- **失去焦点**：边框颜色恢复默认

### 页面切换

- **Tab切换**：底部导航切换，页面淡入淡出
- **页面跳转**：从右侧滑入
- **页面返回**：向右侧滑出
