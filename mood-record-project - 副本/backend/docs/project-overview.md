# 心语项目概述

## 项目简介

**心语** 是一款基于微信小程序的心情记录与社交应用，帮助用户记录每日心情、撰写日记、与好友互动交流，打造一个温暖的情绪管理社区。

## 项目架构

### 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | UniApp + Vue3 | 3.0.0-alpha |
| 状态管理 | Pinia | 2.1.7 |
| 语言 | TypeScript | 5.4.5 |
| 构建工具 | Vite | 5.2.8 |
| 后端框架 | Node.js + HTTP模块 | 原生 |
| 数据库 | JSON文件存储 | - |
| 密码加密 | bcryptjs | 3.0.3 |
| 身份认证 | JWT | 9.0.3 |

## 核心功能

### 1. 心情记录

- 支持6种心情类型：开心、平静、烦躁、难过、生气、焦虑
- 每日心情日历视图

### 2. 日记功能

- 创建、删除日记
- 日记分类（私密/好友可见/公开）
- 添加心情标签
- 日记评论系统

### 3. 社交互动

- 用户注册与登录
- 好友添加与管理
- 世界广场（浏览公开日记）
- 好友私信聊天

### 4. 统计分析

- 心情统计（周/月/年）
- 心情分布图表
- 平均心情和最常心情统计

### 5. 情绪建议

- 根据心情类型提供个性化建议
- 支持6种心情类型的建议内容

## 运行环境

- **Node.js**: >= 14.0.0
- **微信开发者工具**: 最新版本
- **浏览器**: Chrome/Edge 最新版本（H5调试）

## 快速开始

### 后端启动

```bash
cd backend
npm install
npm run dev
```

服务启动后访问: `http://localhost:3000`

### 前端启动

```bash
cd frontend
npm install
npm run dev:mp-weixin
```

使用微信开发者工具打开 `dist/build/mp-weixin` 目录

### 构建命令

| 命令 | 说明 |
|------|------|
| `npm run dev:h5` | H5开发模式 |
| `npm run build:h5` | H5生产构建 |
| `npm run dev:mp-weixin` | 微信小程序开发模式 |
| `npm run build:mp-weixin` | 微信小程序生产构建 |

## 项目特色

1. **简洁架构**: 使用Node.js原生HTTP模块，无复杂框架依赖
2. **跨平台**: 基于UniApp框架，支持H5和微信小程序
3. **情绪关怀**: 内置情绪建议系统，提供温暖的心理支持
4. **数据安全**: 使用JWT认证和bcrypt密码加密
5. **响应式设计**: 适配移动端和PC端
